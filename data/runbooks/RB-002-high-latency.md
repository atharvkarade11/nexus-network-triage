# RB-002 — High Network Latency

## Purpose
Troubleshoot unusually high network response time.

## Symptoms
- Increased round-trip latency
- Application response delay
- Connection timeouts
- Slow service communication

## Investigation Steps
1. Check latency between affected devices.
2. Check packet loss.
3. Inspect interface utilization.
4. Check network congestion.
5. Verify routing path.

## Recommended Actions
- Identify congested network segment.
- Check interface utilization.
- Verify routing path.
- Reduce or reroute traffic if approved.
- Monitor latency after corrective action.

## Escalation
Escalate if latency remains high after network path and utilization checks.
