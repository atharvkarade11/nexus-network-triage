# RB-001 — Network Link Failure

## Purpose
Troubleshoot a network interface or physical link failure.

## Symptoms
- Interface reports DOWN
- Device becomes unreachable
- Packet loss increases
- Connected services may become unavailable

## Investigation Steps
1. Check interface operational status.
2. Check physical cable or optical connection.
3. Verify switch port status.
4. Check interface error counters.
5. Verify routing and neighboring device connectivity.

## Recommended Actions
- Restore the physical connection if disconnected.
- Restart or re-enable the affected interface if appropriate.
- Replace damaged cable or transceiver.
- Escalate if the link remains down after physical checks.

## Escalation
Escalate to network infrastructure team if the physical link and interface remain unavailable.
