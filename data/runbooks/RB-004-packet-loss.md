# RB-004 — Packet Loss

## Purpose
Troubleshoot packet loss affecting network communication.

## Symptoms
- Increased packet loss
- Interface errors
- Link instability
- Application communication problems

## Investigation Steps
1. Measure packet loss over time.
2. Check interface error counters.
3. Check cable and physical connectivity.
4. Check interface utilization.
5. Check for link flapping.

## Recommended Actions
- Inspect the physical connection.
- Check and correct interface errors.
- Replace faulty cable if required.
- Stabilize a flapping interface.
- Continue monitoring after correction.

## Escalation
Escalate if packet loss continues after physical and interface checks.
