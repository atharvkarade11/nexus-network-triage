# RB-003 — Authentication Failure

## Purpose
Troubleshoot repeated authentication failures on network infrastructure.

## Symptoms
- Multiple failed login attempts
- Repeated authentication failures
- Administrator account lockout

## Investigation Steps
1. Identify the source of authentication attempts.
2. Verify whether the source is authorized.
3. Check account status.
4. Review authentication logs.
5. Check for abnormal repeated attempts.

## Recommended Actions
- Verify administrator credentials.
- Unlock the account if authorized.
- Block suspicious sources according to security policy.
- Review authentication logs.

## Escalation
Escalate to the security team if suspicious or unauthorized activity is detected.
